プライバシーポリシー

「いい感じに割り勘」（以下「本サイト」といいます。）では、 利用者のプライバシーを尊重し、情報を適切に取り扱います。

入力情報について

本サイトの割り勘計算で入力された合計金額、人数、負担レベルなどの情報は、 計算のために利用者の端末上で処理されます。 これらの入力内容を本サイト運営者のサーバーへ送信・保存することはありません。

アクセス解析について

本サイトでは、サイトの利用状況や表示性能を把握し、 サービス改善に役立てるため、Cloudflare Web Analyticsを利用しています。

Cloudflare Web Analyticsは、アクセス状況やページの表示性能などの 統計情報を取得します。 分析のためにCookieやlocalStorageを使用せず、 個々の利用者を継続的に追跡することを目的としていません。

Cookieについて

現在、本サイト運営者は利用者を識別・追跡する目的で Cookieを使用していません。

今後、広告サービスその他の外部サービスを導入した場合には、 Cookie等が利用される場合があります。 その際は、本ポリシーを必要に応じて更新します。

外部サービスについて

本サイトでは、サイトの配信およびアクセス解析のために Cloudflareのサービスを利用しています。 外部サービスにおける情報の取り扱いについては、 各サービス提供者のプライバシーポリシー等をご確認ください。

プライバシーポリシーの変更

本サイトの機能追加、利用するサービスの変更、法令等の変更に応じて、 本ポリシーを変更する場合があります。 重要な変更がある場合は、本ページ上でお知らせします。
