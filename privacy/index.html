プライバシーポリシー

「いい感じに割り勘」（以下「本サイト」といいます。）では、 利用者のプライバシーを尊重し、情報を適切に取り扱います。

入力情報について

本サイトの割り勘計算で入力された合計金額、人数、負担レベルなどの情報は、 計算のために利用者の端末上で処理されます。 これらの入力内容を本サイト運営者のサーバーへ送信・保存することはありません。

幹事モードの名簿データについて

「幹事モード」で入力された飲み会名、参加者の名前、負担レベル、出欠、メモ、 集金状況などの情報は、利用者の端末のブラウザ内（localStorage）にのみ保存されます。 本サイト運営者のサーバーへ送信・保存することはありません。

保存されたデータは、ブラウザの設定やサイトデータの削除、 プライベートモードの終了などによって消える場合があります。 重要な内容は「集金表をExcelで出力」などで別途保存してください。

Excelファイルの作成および読み込みも、すべて利用者の端末上で行われます。 「集金案内をコピー」「共有」の各機能は、利用者ご自身が操作したときにのみ動作し、 コピー先や共有先の選択は利用者が行います。

なお、参加者の名前などを扱う性質上、幹事モードのページには広告を掲載していません。

アクセス解析について

本サイトでは、サイトの利用状況や表示性能を把握し、 サービス改善に役立てるため、Cloudflare Web Analyticsを利用しています。

Cloudflare Web Analyticsは、アクセス状況やページの表示性能などの 統計情報を取得します。 分析のためにCookieやlocalStorageを使用せず、 個々の利用者を継続的に追跡することを目的としていません。

広告配信について

本サイトでは、第三者配信の広告サービス「忍者AdMax」を利用しています。

広告配信事業者は、利用者に適した広告を表示するため、 Cookie、ウェブビーコン、広告用IDその他の技術を利用する場合があります。 これらの情報は、広告の配信、効果測定、不正利用の防止などに利用される場合があります。

Cookieについて

本サイト運営者自身は、割り勘計算に入力された情報をCookieに保存して 利用者を追跡することを目的としていません。

一方、広告配信などの第三者サービスによりCookie等が利用される場合があります。 Cookie等の取り扱いについては、各サービス提供者の プライバシーポリシー等をご確認ください。

外部サービスについて

本サイトでは、サイトの配信およびアクセス解析のために Cloudflareのサービスを利用しています。 外部サービスにおける情報の取り扱いについては、 各サービス提供者のプライバシーポリシー等をご確認ください。

プライバシーポリシーの変更

本サイトの機能追加、利用するサービスの変更、法令等の変更に応じて、 本ポリシーを変更する場合があります。 重要な変更がある場合は、本ページ上でお知らせします。
